## The project

A conversational chatbot built end to end: a Next.js interface, models served by Groq, data and authentication on Supabase.

## What it does

- JWT authentication
- Conversation memory
- Public sharing of a conversation
- Modern interface

## Infrastructure

Deployed on Kubernetes, with monitoring and logs.
