## El proyecto

Un clúster Kubernetes (MicroK8s) desplegado en la oferta OpenStack de Infomaniak, descrito como código con Terraform.

## Los componentes

- Terraform para la infraestructura
- MicroK8s para la orquestación
- Longhorn para el almacenamiento persistente
- Ingress para exponer los servicios
