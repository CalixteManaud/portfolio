## The project

A Kubernetes cluster (MicroK8s) deployed on Infomaniak's OpenStack offering, described as code with Terraform.

## Building blocks

- Terraform for the infrastructure
- MicroK8s for orchestration
- Longhorn for persistent storage
- Ingress to expose services
