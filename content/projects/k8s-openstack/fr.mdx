## Le projet

Un cluster Kubernetes (MicroK8s) déployé sur l'offre OpenStack d'Infomaniak, décrit en code avec Terraform.

## Les briques

- Terraform pour l'infrastructure
- MicroK8s pour l'orchestration
- Longhorn pour le stockage persistant
- Ingress pour exposer les services
